**ФинКвиз** — обучающая игра по финансовой грамотности для клиентов Газпромбанка. Пользователи ежедневно проходят короткие сессии с вопросами о банковских продуктах, зарабатывают монеты, поддерживают стрики и повышают свой финансовый IQ в увлекательной форме.

## 🎯 Основные возможности

**Геймификация обучения** — пользователь выступает консультантом банка, помогая клиентам-животным решать финансовые вопросы через интерактивные кейсы с таймером.

**Ежедневное вовлечение** — одна сессия в день по 5 вопросам формирует привычку возвращаться, система стриков мотивирует не пропускать дни.

**Нативная интеграция продуктов** — при правильных и неправильных ответах пользователь получает объяснения с естественными ссылками на продукты банка (ПДС, ИИС, НСЖ, ипотека и др.).

**Прогресс и статистика** — детальная аналитика успеваемости, календарь игр, графики правильных ответов и времени реакции.

**Полностью клиентское решение** — архитектура без бэкенда хранит данные локально через localStorage, что обеспечивает конфиденциальность и простоту интеграции в WebView для MVP.

## 🛠 Технологический стек

**Frontend:** Vue 3 (Composition API), TypeScript, Vue Router, VueUse, Vite.

**Стилизация:** Tailwind CSS 4, кастомные компоненты на базе ShadCN.

**Визуализация данных:** Unovis для построения графиков статистики.

**Анимации:** Motion-v и Neoconfetti для создания плавных переходов и эффектов награждения.

## 🎮 Игровая механика

### Сессия квиза

Каждая сессия состоит из 5 случайно выбранных вопросов из пула в 36 кейсов. Вопросы перемешиваются по алгоритму Fisher-Yates для обеспечения справедливой случайности. К каждому вопросу случайным образом подбирается персонаж-клиент.

### Система наград

За каждый правильный ответ игрок получает монеты в зависимости от сложности вопроса. Награды сохраняются в общий баланс, который отображается на главном экране и может быть использован в будущем «Магазине призов».

### Стрики (серии)

Ежедневная игра увеличивает счетчик стрика. Пропуск дня сбрасывает стрик до нуля, что создает мотивацию для регулярного возвращения. Система учитывает локальный часовой пояс пользователя и корректно обрабатывает переходы через полночь.

### Таймер

На каждый вопрос дается 30 секунд. Таймер использует монотонные часы для точности и корректно обрабатывает сворачивание приложения. При истечении времени показывается правильный ответ без начисления монет.

## 🔮 Дорожная карта

### Ближайшие улучшения

**Тестирование:** Юнит-тесты для движка квиза, E2E тесты критических сценариев, визуальные регрессионные тесты компонентов.

**Оптимизация:** Динамическая загрузка контента, сжатие и оптимизация изображений.

**Аналитика:** Внедрение анонимной телеметрии для отслеживания воронок и улучшения UX, A/B тестирование игровой механики.

### Долгосрочные планы

**Backend** Серверная валидация результатов, API для динамического контента.

**Магазин призов:** Обмен накопленных монет на реальные бонусы — скидки от партнеров, повышенный кэшбэк, участие в розыгрышах ценных призов.

**Расширенная геймификация:** Достижения и бейджи, персонализированные рекомендации продуктов, адаптивная сложность вопросов, тематические недели, боссы и уровни.

**Социальные функции:** Таблица лидеров среди друзей, публикация достижений в соцсетях.
